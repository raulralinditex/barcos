# Créditos de las imágenes de cascos (S34)

Cada casco del Astillero muestra una imagen histórica de su tipo de nave. Todas son de
dominio público o de licencias libres, y se sirven desde este mismo repositorio: el
juego no pide nada a internet al jugar.

La licencia de cada archivo está también en `credits.json`, que es lo que lee el juego
para mostrar el crédito sobre la foto. Sin crédito registrado, la imagen no se muestra.
